# CLI end-to-end and provider success tests

## Background

The initial suite covered orchestration, recovery, budget, redaction, and provider URL rejection,
but did not execute the real CLI against an HTTP model endpoint or cover successful GitHub/GitLab
adapter responses.

## Changes

- Added a loopback OpenAI-compatible Chat Completions server for deterministic CLI integration.
- Exercised CLI configuration, HTTP request shape, JSON mode, Secret redaction, cost accounting,
  SQLite persistence, Markdown output, and Trace inspection in one test.
- Added mocked successful GitHub PR diff retrieval, including Accept and optional authorization
  headers.
- Added mocked successful GitLab MR changes retrieval, path encoding, diff reconstruction, and
  private-token header validation.
- Updated README test documentation.
