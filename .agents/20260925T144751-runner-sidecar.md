# Windows Runner sidecar

## 本次完成

- 新增 PyInstaller one-folder spec。
- 新增隔离构建脚本 `scripts/build_runner.ps1`。
- 构建脚本自动创建 `.runner-build-venv`，避免扫描全局 Python 无关依赖。
- Python 可选依赖新增 `runner` 构建组。
- VS Code 新增 `reviewAgent.runnerPath` 配置。
- 插件优先使用显式 EXE，其次 VSIX 内置 Runner，最后回退 Python 模块。
- 构建产物、隔离环境、VSIX 内 Runner 目录均保持 Git 忽略。

## 构建问题与修复

首次 spec 错误解析项目根路径，已改为使用构建工作目录。第二次构建受到全局 Python 中
旧 cryptography/cffi 包污染，已改为隔离虚拟环境构建。PowerShell 脚本现在显式检查每个
原生命令退出码，失败时不会误报成功。

## 验证

- `review-agent-runner.exe version` 返回 `0.1.0`。
- one-folder 共 87 个文件，约 36.1 MB。
- EXE 启动 FastAPI 成功。
- 带会话令牌访问 `/api/health` 成功。
- 内置 React 页面返回 200 且包含正确标题。
