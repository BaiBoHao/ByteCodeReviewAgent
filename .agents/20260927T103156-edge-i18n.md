# Edge 扩展中英文界面

## 背景

用户确认 Edge 扩展以中文为默认语言，同时需要提供英文选项。扩展已经在用户的日常 Edge
中以解压缩扩展形式安装并启用。

## 本次完成

- 新增轻量双语词典，不引入额外国际化依赖。
- 默认语言固定为简体中文，顶部地球图标可切换 English。
- 语言选择写入 `chrome.storage.local`，关闭或重载侧边栏后仍然保留。
- Ant Design 组件区域同步切换中文和英文 locale。
- 配对页、评审表单、状态提示、按钮、空状态和 Trace 入口均支持双语。
- 严重程度、LEFT/RIGHT 侧别和常见 Finding 类别根据界面语言显示。
- 常见 Runner 配对错误增加中英文友好提示。
- 使用普通卡片列表替代已弃用的 Ant Design `List`，消除浏览器控制台告警。

## 测试与验证

- TypeScript 类型检查通过。
- Vite 生产构建与扩展 ZIP 打包通过。
- `npm audit` 为 0 个已知漏洞。
- Playwright 在 420×900 侧边栏尺寸下验证中文和英文完整界面。
- 验证 English 选择在页面重载后仍然保留。
- 中英文模式下均成功连接本地 Runner 并显示 5 条演示 Finding。
- 最终浏览器控制台无错误或弃用警告。

## 边界

- 本次切换控制扩展界面语言；Finding 标题、解释和建议属于模型生成内容，其语言仍取决于
  模型响应。后续可把当前语言随评审请求传给 Runner，从 Prompt 层控制模型输出语言。
- 已安装的解压缩扩展需要在 `edge://extensions` 点击“重新加载”才能应用本次代码更新。
