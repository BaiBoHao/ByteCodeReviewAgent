# 本地 API 与 Web 界面

## 背景

用户确认先实现本地 API 与本地 Web 页面，并要求使用 React 与 Ant Design，页面风格精致、
优雅且简洁。该阶段基于已完成的 `codex/phase-one-backend-cli` 创建堆叠分支
`codex/local-web-ui`。

## 后端 API

- 新增 FastAPI 本地应用与 `review-agent serve` 命令。
- 服务固定监听 `127.0.0.1`，CLI 不提供公网监听选项。
- 提供健康检查、脱敏配置状态、工具列表、历史 Run、Run 详情、Trace、后台评审任务和恢复接口。
- 后台任务使用现有 `ReviewService`、SQLite、预算、checkpoint、Trace 和 Markdown 报告逻辑。
- API 配置状态只返回 Key 是否存在，不返回 Key 内容。
- 未启用 CORS，避免普通外部网页直接跨域调用本机 API。
- 评审使用后台线程执行，页面通过短轮询刷新任务状态。

## React 与 Ant Design 页面

- 新增 Vite、React、TypeScript 与 Ant Design 前端工程。
- 提供快速评审表单、预算输入、配置健康状态、运行进度、统计卡片和历史运行列表。
- 提供 Finding 抽屉，区分高置信度与仅供参考问题。
- 提供 Trace 证据链弹窗。
- 支持桌面双栏和移动端单栏响应式布局。
- 构建产物写入 Python 包内的 `web_dist`，安装 Wheel 后仍可直接启动页面。
