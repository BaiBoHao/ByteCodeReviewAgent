# 配置说明

## 快速开始

在项目根目录复制示例配置：

```powershell
Copy-Item .env.example .env
```

编辑 `.env`，至少填写以下五项：

```dotenv
REVIEW_AGENT_LLM_BASE_URL=https://api.example.com/v1
REVIEW_AGENT_LLM_API_KEY=你的密钥
REVIEW_AGENT_LLM_MODEL=模型名称
REVIEW_AGENT_LLM_THINKING=disabled
REVIEW_AGENT_INPUT_PRICE_CNY_PER_MILLION=输入价格
REVIEW_AGENT_OUTPUT_PRICE_CNY_PER_MILLION=输出价格
```

`REVIEW_AGENT_LLM_THINKING` 是可选的兼容参数。DeepSeek 等默认启用思考模式的服务在
结构化 JSON 评审中可能把输出额度全部用于推理；此时建议设置为 `disabled`。其他服务商
不支持该字段时应留空。

`.env` 已经包含在 `.gitignore` 中，不会被正常 Git 提交。它仍然是本机明文文件，
只适合当前 CLI 开发阶段；未来 IDE 插件应改用操作系统或 IDE 的 Secret Storage。

## 检查配置

运行：

```powershell
$env:PYTHONPATH = "src"
python -m bytecode_review_agent doctor
```

`doctor` 只会显示 API Key 是否已配置，绝不会输出 Key 内容。

## 指定其他配置文件

如果不想在当前目录放置 `.env`：

```powershell
python -m bytecode_review_agent doctor --env-file E:\secure\review-agent.env

python -m bytecode_review_agent review changes.diff `
  --env-file E:\secure\review-agent.env `
  --budget 10
```

也可以设置：

```powershell
$env:REVIEW_AGENT_ENV_FILE = "E:\secure\review-agent.env"
```

## 配置优先级

从高到低为：

1. CLI 显式参数，例如 `--model`、`--base-url` 和 `--input-price`。
2. 当前进程的环境变量。
3. `--env-file`、`REVIEW_AGENT_ENV_FILE` 或当前目录 `.env`。
4. 程序默认值。

## 安全注意事项

- 不要把真实 API Key 写进 `.env.example`。
- 不要提交 `.env`。
- 不要在日志、Issue、PR 或聊天中粘贴 Key。
- 云端模型只接收完成本地脱敏后的上下文。
- 只读取私有仓库时，GitHub/GitLab Token 应使用最小只读权限。
- 发布 GitHub PR 评论时，`GITHUB_TOKEN` 需要 Fine-grained Token 的
  `Pull requests: Read and write` 权限；不要授予仓库管理、工作流或其他无关权限。
